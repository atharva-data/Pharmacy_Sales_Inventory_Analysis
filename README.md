# Pharmacy_Sales_Inventory_Analysis
End-to-end Pharmacy Sales &amp; Inventory Analysis using Python, Pandas, SQL, Excel, and Power BI. Developed interactive dashboards to analyze sales, revenue, top-selling medicines, stock availability, low-stock items, and expired medicines to support data-driven business decisions.

The Pharmacy Sales & Inventory Analysis project focuses on analyzing pharmacy sales performance and inventory management using Python, Pandas, SQL, Excel, and Power BI. It involves data cleaning, exploratory data analysis, SQL querying, and interactive dashboard development to track revenue, sales trends, best-selling medicines, stock availability, and expired or near-expiry medicines, helping businesses make data-driven decisions.
